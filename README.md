## English

I build and break automated trading systems.
One question runs through everything I write: **how do you tell when AI-generated code is lying to you?**&#8203;

Four repositories, four versions of that same question:

- A backtest looks great — is it real, or is it overfitting with costs and fills left out?
- An AI-written trading bot's logs are all green — is it actually doing anything?
- The "money flow" figure in an exchange app — what is it actually measuring?
- An AI agent pulls macro data on a schedule — how do you know it isn't making things up?
